Comando en CMD para ver la IP general y otros datos de la red:

ipconfig



Comando en CMD para ver algunos de los disposivos conectados a la red (pero sin identificar):

for /L %i in (1,1,254) do @ping -n 1 -w [IPv4].%i | findstr "TTL="
(substituir "[IPv4]" por la IPv4 de la red en la que se hace)



Comando en PowerShell para ver la mayoría de los dispositivos conectados a la red identificados:

Get-NetNeighbor -AddressFamily IPv4 | Where-Object {$_.State -ne "Unreachable"} | ForEach-Object {
    $ip = $_.IPAddress
    try {
        $name = [System.Net.Dns]::GetHostEntry($ip).HostName
    } catch {
        $name = "-"
    }
    "$ip`t$name"
}

O también usar (más compatible):

1..254 | ForEach-Object {
    $ip = "[IPv4].$_"
    if (ping.exe -n 1 -w 100 $ip | Select-String "TTL=") {
        try {
            $name = ([System.Net.Dns]::GetHostEntry($ip)).HostName
        }
        catch {
            $name = "-"
        }
        "$ip`t$name"
    }
}
(substituir "[IPv4]" por la IPv4 de la red en la que se hace)



Comando en CMD para comprobar el nombre de un dispositivo mediante su IP privada:

ping -a [IP]
(Substituir "[IP]" por la IPv4 del dispositivo objetivo)



Comando en CMD para descubrir el usuario en el que está la sesión iniciada en un ordenador Windows mediante el nombre:

quser /server:[NOMBRE-PC]
(Substituir "[NOMBRE-PC]" por el nombre del equipo objetivo)



Comando en CMD para mandar un mensaje remoto a otro ordenador mediante el nombre de equipo:

msg * /server:[NOMBRE-PC] "mensaje"
(Substituir "[NOMBRE-PC]" por el nombre del equipo objetivo)



Comando en CMD para consultar los puertos abiertos en la red conectada:

netstat -ano
