INFORMACIÓN SOBRE LOS DISTINTOS MALWARES DE ESTE FLASH DRIVE:



(Para ocultar cualquier virus hay que usar un acceso directo al que se le puede cambiar el nombre y ponerle un icono de los que hay descargados en la unidad para que parezca otro programa.)

- chrome1M: Ejecuta el navegador "Google Chrome" un millón de veces simultáneamente.

- cmdBucle: Ejecuta la terminal de Windows "cmd" durante infinitas veces (es un bucle). Para detener el proceso, hace falta entrar a WIN + R, introducir este comando: taskkill /f /im cmd.exe y ejecutarlo.

- PcOFF: Incluye 2 carpetas, una que contiene un archivo que apaga el ordenador al instante en el que se ejecute y otra que tiene diversos archivos con cuentas regresivas programadas para apagarlo según el tiempo elegido.

- PcRELOAD: Incluye 2 carpetas, una que contiene un archivo que reinicia el ordenador al instante en el que se ejecute y otra que tiene diversos archivos con cuentas regresivas programadas para reiniciarlo según el tiempo elegido.

- ViMens: Ejecuta un script que hace que empiecen a aparecer ventanas con mensajes inquietantes en la pantalla, saludando y afirmando que no se va a ir. Para detener el proceso solo hay que eliminar la tarea en el administrador de tareas de "Windows".

- ViSonid: Ejecuta un script para que el ordenador empiece a dictar mensajes de "tienes un virus" por el altavoz. Para detener el proceso solo hay que eliminar la tarea en el administrador de tareas de "Windows" pero más abajo con el resto de procesos no principales.

- ViPorn: Ejecuta un script que simulando un falso virus de pornografía que hace que empiezen a aparecer ventanas con mensajes explícitos en la pantalla. Para detener el proceso solo hay que eliminar la tarea en el administrador de tareas de "Windows".

- ViSys: Ejecuta un script que simulando una alerta de virus emitida por "Windows Defender" que hace que empiezen a aparecer ventanas con mensajes de aviso en la pantalla. Para detener el proceso solo hay que eliminar la tarea en el administrador de tareas de "Windows".

- WiCrash (experimental): Contiene un código que ejecuta el comando "wininit" en la "PowerShell de Windows" para que reinicie el sistema operativo y salte un BSOD (pantallazo azul).
